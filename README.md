# CO:IT Android Application

CO:IT is a real-time communication platform designed specifically for students and teachers to facilitate structured academic interactions. The application centralizes announcements, discussions, and resource sharing in one easy-to-use mobile interface.

---

## 🚀 Key Features

- 💬 Real-time chat functionality for seamless communication  
- 📢 Noticeboard for announcements and important updates  
- 📝 Note sharing to improve collaboration and resource access  
- 🔐 Secure user login using Firebase Authentication  
- 🔔 Instant notifications via Firebase Cloud Messaging  

---

## 🛠️ Technologies Used

- Flutter & Dart for cross-platform mobile development  
- Firebase Authentication for secure user access  
- Firebase Cloud Messaging for push notifications  
- Firebase Firestore for real-time data syncing  
- Android Studio as the development environment  

---

## 🚧 Getting Started

1. Clone or download this repository.  
2. Open the project in Android Studio or your preferred Flutter IDE.  
3. Run `flutter pub get` to install dependencies.  
4. Configure Firebase project with your app (replace `google-services.json`).  
5. Build and run the app on Android or iOS emulator/device.  
6. Sign up or log in using Firebase Authentication to start interacting.  

---

CO:IT simplifies academic communication by integrating essential collaboration features into a single app, enabling students and teachers to stay connected and informed easily.
